# Claude Code Project Instructions

## General
- Follow existing project patterns and architecture.
- Use established .NET and C# best practices.
- Keep changes focused and avoid unnecessary abstractions or refactoring.
- Do not commit or push unless explicitly asked.
- Do not update the README unless explicitly requested.

## Code Changes
- Prefer short, single-line comments. Add comments around significant new code or non-obvious behavior, but avoid explaining code that is already self-explanatory. Use multi-line comments only when additional context is genuinely needed.
- Preserve existing functionality unless the requested change requires modifying it.
- Do not modify the existing BART summarization pipeline unless explicitly requested.

## Workflow
- Before making changes, briefly explain the plan.
- After changes, report what changed and show relevant Git status/diff information.
- Build the project after meaningful code changes and run available automated tests when applicable.
